# Provenance

SaintNova Executor is a renamed public release derived from the Aether project
(2026). The original Aether codebase was developed in a private workspace.
Internal identifiers and branding were renamed to SaintNova for this release.

This repository contains the Studio executor, the local harness, the protocol,
the UI, and the tests. The Player research and the kernel experiments from the
original workspace are not included.

Third-party components and their licences are listed in `THIRD_PARTY_NOTICES.md`.
